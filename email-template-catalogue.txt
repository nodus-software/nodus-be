NODUS HEALTH EMAIL TEMPLATE CATALOGUE
=====================================

This catalogue contains the email templates currently supported by the backend
and the additional account, security, and administrative templates recommended
for future implementation.

All templates should support HTML and plain-text rendering. Shared variables:

- recipient_name
- organization_name
- support_url
- support_email
- current_year
- app_name
- app_url

Security emails must not expose patient information, clinical data, passwords,
MFA secrets, backup codes, or full authentication tokens as visible text.


1. ORGANIZATION ACTIVATION
--------------------------
Template ID: organization_activation
Status: Sending exists; template integration needed.
Subject: Activate your {{app_name}} organization
Trigger: A founder registers a new organization.
Required variables: recipient_name, organization_name, activation_url, expires_at
CTA: Activate organization

Content:

Hi {{recipient_name}},

Your organization, {{organization_name}}, has been registered on {{app_name}}.

Activate the organization and create your administrator credentials using the
button below.

Activate organization: {{activation_url}}

This link expires on {{expires_at}} and can only be used once.

If you did not register this organization, contact support immediately.

MFA NOTE
--------
The current system uses authenticator-app TOTP rather than emailed login codes.
Do not create an email OTP template unless email is deliberately introduced as
an MFA method.
